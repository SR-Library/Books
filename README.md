# سجاد ثامر — مكتبة الروايات (منصّة نشر)

تطبيق ويب عربي لعرض الروايات وحلقاتها بصيغة PDF على شكل رفوف كتب. المحتوى تضيفه إنت
من الأكواد، والمستخدمون يقرؤون فقط — يشوفون الروايات والتحديثات بدون ما يعدّلون شيئًا.

## هيكل المشروع

```
index.html            ← الصفحة الرئيسية
app.js                ← منطق التطبيق (لا تحتاج تعدّله)
styles.css            ← التصميم
library.js            ← ★ قائمة ملفات الكتب + روابط التواصل مع الكاتب
books/                ← ★ كل كتاب بملف مستقل
  └─ book-02.js
covers/               ← صور الأغلفة
pdfs/                 ← ملفات PDF للحلقات
service-worker.js     ← للعمل بدون إنترنت
```

## كيف تضيف رواية جديدة؟  (٣ خطوات)

**١) حطّ ملفات الـ PDF**
انسخ ملفات حلقات الرواية داخل مجلد `pdfs/`. مثلًا:
`pdfs/my-book/ch1.pdf`, `pdfs/my-book/ch2.pdf`

**٢) سوِّ ملف الكتاب**
انسخ `books/book-02.js` وسمِّه باسم جديد مثل `books/my-book.js`، وعدّل بياناته:

```js
SAJJAD.register({
  id: 'my-book',                 // معرّف فريد بالإنجليزي بدون مسافات
  title: 'اسم الرواية',
  author: 'سجاد ثامر',
  category: 'ساموراي',           // أي تصنيف تريده، ويظهر كزر فلترة بالمكتبة
  description: 'نبذة قصيرة...',
  cover: 'covers/my-book.jpg',   // اتركها '' لغلاف تلقائي ملوّن
  chapters: [
    { number: 1, title: 'الحلقة الأولى', pdf: 'pdfs/my-book/ch1.pdf' },
    { number: 2, title: 'الحلقة الثانية', pdf: 'pdfs/my-book/ch2.pdf' },
  ],
});
```

> الغلاف يُعرض بنسبة صفحة الكتاب (تقريبًا A4)، فأي غلاف بهذه النسبة يركب على الرف بدون قص.

**٣) سجّل الملف في المكتبة**
افتح `library.js` وزيد اسم الملف بالقائمة:

```js
window.SAJJAD.BOOK_FILES = [
  'books/book-02.js',
  'books/my-book.js',   // ← السطر الجديد
];
```

خلص. التطبيق راح يعرض الرواية تلقائيًا على الرف.

## روابط التواصل مع الكاتب

افتح `library.js` وحط روابطك داخل `window.SAJJAD.contacts` (واتساب، تلكرام، انستغرام،
تيك توك، سناب شات، فيسبوك). الزر اللي رابطه فارغ يظهر للمستخدم برسالة "الرابط غير مضاف بعد".
الأزرار تظهر في صفحة **الإعدادات**.

## المكتبة والمفضلة

- صفحة **المكتبة** فيها رفّان: **مكتبتي** (الروايات اللي ضغط عليها المستخدم ♡) و**كل الروايات**.
- كل رواية يضيفها المستخدم للمفضلة تنحط تلقائيًا كأنها كتاب على رفّه.

## تعديل أو حذف رواية

- **تعديل الاسم أو الحلقات:** افتح ملف الكتاب في `books/` وعدّل مباشرة.
- **حذف رواية:** احذف سطرها من `library.js` (وتكدر تحذف ملفها وملفات PDF).

## ما الذي يبقى للمستخدم؟

المفضلة، سجل القراءة، آخر صفحة وصلها، واسم القارئ، والمظهر — كلها تُحفظ
على جهاز كل مستخدم محليًا، ولا تؤثر على بقية المستخدمين.

## ملاحظات

- الحلقات تُفتح كملف PDF داخل قارئ مدمج (أبيض / بني / داكن).
- الموقع يعتمد الشبكة أولًا، فالتحديثات تظهر مباشرة. ومع ذلك، لو بدّلت ملفات أو أضفت
  كتب، رفّع رقم النسخة في `service-worker.js` (مثلًا `sajjad-library-v3` → `v4`).
